# 근무조 및 근태 관리 시스템 (ShiftWork)

이 애플리케이션은 통상조 및 4개 교대조(1조, 2조, 3조, 4조)의 순환 근무 일정을 자동으로 계산하고, 사원 정보 및 일별 근태 현황을 직관적으로 관리할 수 있는 모던한 SPA 웹 애플리케이션입니다.

## 🛠️ 기술 스택
- **프론트엔드**: HTML5, Vanilla JavaScript, Modern CSS (Glassmorphism UI)
- **아이콘**: Lucide Icons (CDN)
- **폰트**: Google Fonts (Outfit, Inter, Nanum Square Neo)
- **데이터 저장**: 웹 브라우저 로컬 스토리지 (`localStorage`)

## 📅 근무조 교대(Rotation) 규칙
4개 교대조(1조, 2조, 3조, 4조)는 매일 아래의 순서로 로테이션을 돕니다:
- **근무 종류**:
  - **A조 (Day)**: 오전 근무 (예: 06:00 ~ 14:00)
  - **B조 (Evening)**: 오후 근무 (예: 14:00 ~ 22:00)
  - **C조 (Night)**: 야간 근무 (예: 22:00 ~ 06:00)
  - **휴무 (Off)**: 비근무 일

- **기본 회전 패턴 (4일 주기)**:
  - 1일차: 1조(A) | 2조(B) | 3조(C) | 4조(휴무)
  - 2일차: 4조(A) | 1조(B) | 2조(C) | 3조(휴무)
  - 3일차: 3조(A) | 4조(B) | 1조(C) | 2조(휴무)
  - 4일차: 2조(A) | 3조(B) | 4조(C) | 1조(휴무)
  - 5일차(반복): 1조(A) | 2조(B) | 3조(C) | 4조(휴무)

*통상조는 교대 근무 회전 규칙에 영향을 받지 않으며, 일반 주간 근무(예: 평일 09:00 ~ 18:00 근무, 주말 휴무)를 기준으로 동작하되 달력에서 직접 상세 근태를 관리할 수 있습니다.*

## 🚀 시작하기
이 프로젝트는 순수 웹 표준 기술로 개발되어 빌드 과정 없이 웹 브라우저에서 즉시 열어볼 수 있습니다.

### 1. 로컬에서 실행하기
터미널을 열고 프로젝트 폴더 내에서 다음 명령어를 실행하여 웹 서버를 띄울 수 있습니다:

```bash
# Node.js 패키지가 있을 경우
npx live-server

# 또는 파이썬을 이용한 실행
python3 -m http.server 8000
```
웹 브라우저에서 `http://localhost:8000` 또는 `live-server`가 열어준 주소로 접속합니다.

## 💡 주요 화면 및 기능
1. **대시보드 (Dashboard)**: 오늘의 근무조 현황, 오늘의 근무/휴무 사원 요약, 근태 비율 요약 카드를 표시합니다.
2. **근무 스케줄 (Calendar)**: 월별 달력 형태로 각 날짜별 근무조(A, B, C, 휴무) 배열을 한눈에 보고, 날짜를 클릭하여 사원별 근태(출근, 결근, 휴가, 지각, 조퇴 등)를 기록합니다.
3. **사원 관리 (Employee Management)**: 신규 사원을 이름 및 근무조(통상조, 1~4조)를 설정해 등록하고, 정보를 수정/삭제합니다.
4. **근태 통계 (Statistics)**: 사원별 및 근무조별 월간 근태 통계를 테이블과 시각 차트로 한눈에 모니터링합니다.
5. **데이터 설정 (Data Management)**: 교대조 시작 기준일 설정 및 전체 데이터 백업(JSON Export), 데이터 복구(JSON Import) 기능을 지원합니다.
